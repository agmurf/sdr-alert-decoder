SITE METADATA IS NOT INCLUDED
=============================

This installer ships NO site register. Sensor registers are agency data and
not ours to redistribute, so the decoder reports exactly what came off the
air - sensor ID, value and timestamp.

Readings from stations it has no metadata for are shown with their raw value
and labelled "no site register loaded - raw value". That is normal, not an
error. To label readings, place your own agency's Sensors.xlsx next to the
installed executable.

WHAT THIS DOES AND DOES NOT DO
==============================

It is a passive receiver. It decodes ALERT flood telemetry that is already
being broadcast; it transmits nothing.

Decoded values are NOT an official data source. Check the transmitting
agency's own feed before acting on any reading - a decode can be wrong, and
ALERT1 has no way to signal "no reading" (a station holds its last good value
instead, which reads as fresh data).
